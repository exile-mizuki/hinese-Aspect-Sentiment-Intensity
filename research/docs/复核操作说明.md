# 人工复核操作说明

优先打开 `数据审计与复核.xlsx` 的 **训练OOF24例** 工作表，或 `error_analysis/新增训练折外24例_待人工复核.csv`。其中“真值”来自原训练标注，“原预测/新预测”均是**该条不在对应训练折中时**的模型预测；不能据此说训练数据完全独立于模型开发过程。

每人阅读原句时，将**人工确认标签**填写为“否定作用域 / 转折作用域 / 程度词 / 隐含方面 / 指代 / 多方面关系 / 标注歧义 / 其他 / 未发现明显问题”的一项或多项；再填写“人工解释”，说明为何原模型或候选的预测偏差可能出现，不能只根据大/小分数推断模型好坏。多标签用中文分号分隔。

请尤其区分：

- **V 是愉悦度正负，A 是情绪唤醒强弱**。激烈的负面评价也可能高 A。
- 正文里出现“不”不意味着针对当前 aspect 的否定，例如“不是特别贵但是服务很好”要先定位方面。
- 同句多个 aspect 可能需要不同分数。
- 原数据多 opinion 的均值聚合不是错误本身。
- 如怀疑官方标签，标注为“有歧义”并说明；**不直接覆盖训练 JSON**。

原项目的 `原项目24例_保留待人工复核.csv` 取自 **Test**，可用于事后报告与定性解释，不能用其结论重新设计损失权重或进行参数选择，否则等于继续在测试集上调参。

复核时建议两位同学独立阅读同样的 5～10 条，先讨论类别判定一致性，再分工完成其余样本；这是建议，**尚未执行**。填写结果提交后才能补充真正的人为错误原因统计。
