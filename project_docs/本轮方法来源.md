# 本轮改进的方法来源与边界

查阅日期：2026-11-19。主题：高 A 强度预测、按评论分组验证、错误类型细分。

## 实际查阅的公开实现

- [YNU 同题代码](https://github.com/WZH5127/2024_subtask1_intensity_prediction/blob/011376020d0425d72f7c28042ef3ae966f7a3684/valence_arousal_pretrain.py)：BERT pooled output 接两个线性回归头，使用 L1 损失；方面词与句子拼接，随机划分训练行。我们保留双目标回归思路，使用现有 CLS 版本和方面标记，并增加按评论及重复正文分组的验证。没有复制其训练循环。
- [CCIIPLab 仓库](https://github.com/tongzeliang/SIGHAN2024)：此次公开页面只有 README，不能据此声称复现了它的模型或训练方法。
- [官方任务仓库](https://github.com/NYCU-NLP/SIGHAN2024-dimABSA)：继续沿用已有数据和官方评分函数，不把别人的排行榜成绩当作我们同条件下的实验结果。

## 同题论文给出的方向

[HITSZ-HLT 论文](https://aclanthology.org/2024.sighan-1.20.pdf) 第 3.2、3.4 节使用连续回归和离散强度分类两个模型，并在 Subtask 1 平均预测。回归使用 MSE，分类使用交叉熵。我们据此设计 A 的 MSE 对照，以及共享编码器的 A 三档辅助分类；后者是本项目的轻量调整，并非论文的原样复现。

## 本项目具体实现

1. `marked_l1`：方面标记 + V/A 平均 L1，作为同条件对照。
2. `arousal_mse`：V 保持 L1，A 改为 MSE，考察大误差惩罚的影响。
3. `arousal_mse_aux`：在第 2 组上添加 A 三档交叉熵，权重 0.1；档位为 A<5、5≤A<6.5、A≥6.5。类别权重只用当折训练标签计算。推理仍由回归头给出连续分数。

所有方法相同编码器、方面标记、随机种子、优化器和固定 3 轮训练。随机初始化的辅助层在三个方法中均创建，避免因多创建一层而改变初始随机序列；对照组不使用其输出。

按评论 ID 合并同评论句子，再用完全相同正文连接不同评论，得到连通组。使用 [GroupKFold](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.GroupKFold.html) 做 3 折；每个样本仅获得一次未参与该模型训练的预测。没有用留出折挑选最佳轮次；也没有做近重复文本检测。分组方法是本项目增加的可靠性检查，不声称出自上述 GitHub 代码。

错误分析增加否定、转折、程度强调、隐含评价候选、指代、同句多方面、重复方面等线索，并保留命中文字和位置。规则标签仅便于定位案例，不等于人工标注或已证实的错误原因。24 条复核案例的人工填写栏保持空白。

## 结果使用规则

先固定实验方案并完成训练集内部交叉验证，再读取官方开发集和测试集作对照。候选须同时改善 A 总体误差与高 A 误差，且 V/A 平均误差相对同条件基线增幅不超过 0.003，才通过筛选。官方开发集再应用相同门槛；测试集不参与采用决策。

既往已查看过官方测试集，本轮测试结果属于探索性比较，不能包装成新的、从未查看过的独立测试。3 折均值和标准差只描述当前划分的波动，不等于多随机种子结论或显著性检验。
