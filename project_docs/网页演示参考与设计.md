# 网页演示参考与设计

查阅日期：2026-11-20。页面及服务为本项目独立编写，没有复制第三方界面、模型权重或整段实现。

## 参考的实际项目

- [PyABSA Gradio 演示的 app.py](https://github.com/aunraza19/Aspect-Based-Sentiment-Analysis/blob/master/src/app.py)：借鉴“文本输入 → 示例 → 按方面查看结果”的操作顺序。该项目包含方面抽取和极性分类；我们仍按课程 Subtask 1 接收用户指定方面，输出连续 V/A 分数。
- [PyABSA 官方 Flask 接口示例](https://pyabsa.readthedocs.io/en/v2/3_inference/APC_flask_demo.html)：参考浏览器与预测接口分离的方式。该示例在请求中创建分类器；本项目启动时加载模型并复用，减少课堂等待，且无需新增 Flask 依赖。

## 为本项目增加的内容

- V/A 二维图，与逐方面数值、评分表相互对应；轴范围始终为 1–9，参考线 5 不是类别阈值。
- 正式演示模型和实验候选明确分开；默认使用原选定模型。打开对比后，候选标为未通过开发集门槛，不将分数变化命名为效果提升。
- 修改输入后明确提示旧结果属于上次提交；导出与历史回看都使用保存的请求快照，而不是当前正在编辑的输入。
- 长文本在实际分词后检查 128 上限；不自动截断。保留方面词与对应上下文是演示前的输入要求。
- 原文方面位置高亮采用字面匹配，不伪装成注意力或模型解释。
- 原生网页和 Python 标准库服务，复用已有 NLP 环境；无远程字体、CDN、广告或外部分析请求，支持离线演示。
- 仅本机监听，静态文件白名单、请求会话检查、单次推理锁、输入边界校验；导出 CSV 防公式触发。

页面的实验数字来自当前项目保存结果；演示句和交互截图不作为独立测试集或准确率证据。
