# 观感 · 网页演示使用说明

## 怎样打开

进入当前项目文件夹，双击 **启动网页演示.cmd**。它会自动打开浏览器，默认地址为 `http://127.0.0.1:8765`。保持启动窗口开启，等网页右上角显示“本地模型已就绪”，即可分析。

你现在的 test1 环境已经具备全部依赖，不需要安装 Node.js、Gradio 或 Flask。前端使用原生 HTML/CSS/JavaScript，后台直接加载已有模型，整个演示可以断网运行。第一次启动需要载入两个模型，后续分析复用模型，不会每次重新训练。

如果浏览器没自动打开，把启动窗口显示的本地地址复制到浏览器。若端口占用，会尝试后续端口；重复启动同一项目会复用已有服务。演示结束，在启动窗口按 Ctrl+C 关闭。只关闭网页不会停止后台服务。

## 课堂上怎么操作

1. 点击“有好有坏”，会填入“汤非常难喝，但是服务很好。”及方面词“汤，服务”。点击“开始分析”。
2. 指着两个方面的分数解释：V 越高越正面，A 越高情绪越强烈；两个分数都是 1–9 的连续回归值，不是概率。
3. 把评论改成“汤非常好喝，但是服务很差。”，再点击分析。比较两个方面的变化。修改输入后，旧结果会提示“上次提交”，避免把新文字和旧分数混用。
4. 勾选“同时对比实验候选”，再分析。坐标图中的实心圆表示当前模型，空心菱形表示候选。候选未通过开发集门槛，仅供研究对照，分数升高不是准确率提高。
5. 展开“完整评分表”，或点击“导出 CSV / JSON”保存本次输入、模型标识及预测结果。可用右上角“展示模式”简化页面，按 Esc 退出。

页面保留最近 5 次分析，点击记录可以回看；记录只在页面内存中，刷新即清空，后台不自动保存评论。导出的文件由浏览器保存到其下载目录。

## 输入规则

- 方面词由你指定，不做自动方面抽取。方面词需要出现在原文里；最多 8 个，重复词自动合并。
- 建议输入一到两句餐饮评论。界面最多 500 字符，后台还会检查完整“方面 + 标记后的评论”的分词长度；超过 128 词元会拒绝并提示缩短，避免默默丢掉后半句。
- `NULL` 可表示隐式方面；它没有可高亮的字面位置。普通演示建议用原文中的具体方面词。
- 字词高亮只显示指定方面在原文里的位置，不是注意力图，也不是模型预测依据的证明。
- 网页输入为中文餐饮评论；跨领域、反讽、复杂关系和强烈情绪仍可能预测不准。三个示例是自拟演示句，没有人工评分真值。

## 当前使用哪个模型

默认模型：上轮选定的方面标记模型，seed 42、第 2 轮。

可选研究对照：本轮 `arousal_mse_aux`，seed 42、第 3 轮。其开发集表现变差，因此没有替换默认模型。

网页“实验依据”中的 L1 对照是本轮重新训练的第 3 轮模型，不是默认演示模型；表格已明确标注这一点。指标从已有实验结果文件加载，未为网页改写。测试集比较属于探索性结果。

## 文件位置与分享

- `web/index.html`、`web/style.css`、`web/app.js`：网页界面。
- `src/web_demo.py`：本地服务与真实模型推理。
- `src/check_web_demo.py`：接口复核，需先启动网页服务。
- `results/web_demo/`：接口和浏览器检查记录、界面截图。
- `网页演示参考与设计.md`：参考来源、借鉴部分与本项目的区别。

分享时使用“中文方面情感强度预测-网页演示完整版.zip”，其中已经包含网页、所需模型权重、分词器及历史技术成果。同学的电脑仍需具备原项目 Python 依赖。不要直接双击 HTML 文件，它需要本地 Python 服务才能预测。

服务只监听本机地址，手机布局适配不代表手机可以通过局域网访问。此版面向本地课堂演示，没有做公网部署。
