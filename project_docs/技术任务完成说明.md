- `raw_source_counts.csv`：两份训练文件分别为 4,151 和 4,372 条标注，共 8,523 条，按句子 ID、文本、方面合并为 7,476 个实例。
- `split_statistics.csv`：训练、开发、测试分别为 6,050/100/2,000 句及 7,476/115/2,658 个方面。空文本、缺失和越界标签均为 0，训练的 150 个 NULL 隐含方面保留。
- `cross_split_overlap_counts.csv` 与 `cross_split_overlap_details.csv`：训练—开发、训练—测试、开发—测试分别有 1/4/1 个完全相同的“文本＋方面”键。主实验沿用官方划分，报告披露重叠情况。
- `aggregation_example_raw.csv` 与 `aggregation_example_mean.csv`：同方面多个意见取均值的真实例子。肉粿三个意见的 V/A 均值为 6.3300/6.2067。
- `label_distribution.png` 和 `数据说明.md`：可交给 D 的分布图与数据处理文字。

能讲清的三个问题：句子数为何少于方面数；NULL 表示什么；为什么对同一方面的多个意见取均值。

## B：实验复核与重复训练

脚本：`src/experiment_analysis.py`。交付目录：`results/experiment_analysis/`。

已重新调用官方评分函数核对六组方法，并核对三个种子的两组 BERT，共六次模型运行、12 份开发/测试预测。新增种子 17、2026 的训练已真实完成，日志和预测保存在 `results/repeats/`。每次均训练 3 轮，由开发集两维平均 MAE 选检查点。

| 测试模型 | V-MAE | V-PCC | A-MAE | A-PCC |
|---|---:|---:|---:|---:|

## C：12 个典型案例

脚本：`src/case_analysis.py`。交付目录：`results/case_analysis/`。

- `12个案例.csv`：4 个改善、4 个明显误差、4 个同句方面混淆或打平案例，来自 12 条不同评论。
- 每例含 ID、原句、方面、人工 V/A、三种方法预测、绝对误差及结合原文的原因分析。
- `同句方面对照.csv`：额外保存 4 个混淆案例的对照方面和排序数值。
- `案例分析.md`：错误类型总结及推荐展示的 C01、C07、C11。分别讲转折中区分服务与食物、强烈负面情绪的强度低估、长句多个对象混淆。

每例由脚本按 ID 与方面词回查保存的测试预测，选择规则也在 `selection_log.json` 中记录。这是定向选例，各类数量不代表总体错误比例。原因分析依据原句和模型输出，不能证明模型内部关注了哪些词。
